# FreEDoom weapon sprites

These standalone PNG files were exported from FreEDoom 0.13.0 by `DEV-tools/extract-freedoom-weapons.js`. Potato Strike loads only these files; the original WAD is not needed at runtime or in release packages.

Source project: https://freedoom.github.io/

# Potato Strike 1.2 BETA FINAL

This branch contains the same gameplay and Studio runtime as 1.2 FINAL.

The reduced download is generated with:

```text
npm run package:beta-final
```

Output: `PotatoStrike-1.2-BETA-FINAL.zip`.

The compressed beta keeps the game, editor, offline runtime, configs and default mods. It omits developer tools, platform source trees, compatibility helpers, example mods and unreleased prototypes.

# Unreleased Mods

Tu trafiaja moje eksperymentalne pomysly do przyszlych wersji Potato Strike.

Folder `1.2-beta/` zawiera importowalne JSON-y do zakladki `Mody` albo Studio. Te pliki sa celowo lekkie: mapa, ustawienia trybu i ewentualnie bron. Nie wymagaja dodatkowych tekstur ani duzych assetow.

Zasada branchy:

- `unreleased` - pomysly, szkice, eksperymenty.
- `beta` - rzeczy wybrane do publicznego testu.
- `main` - wydanie po potwierdzeniu.

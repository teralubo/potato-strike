# Potato Strike 1.2 BETA Ideas Pack

Importuj te pliki przez menu `Mody`:

- `aim-lab-bunker.json` - trening celowania i recoil.
- `extraction-sweep.json` - prototyp story/extraction.
- `micro-royale.json` - szybki maly tryb walki.

Kazdy mod zawiera wlasna lekka mape i moze byc wlaczony/wylaczony w menu modow. Jesli kilka modow jest aktywnych naraz, najnizszy priorytet jest stosowany pierwszy.

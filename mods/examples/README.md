# Example Mods

Tu sa lekkie przykladowe mody do importu, testowania i przerabiania w Potato Strike.

Folder `1.2-beta/` zawiera importowalne JSON-y do zakladki `Mody` albo Studio. Pliki sa celowo lekkie: mapa, ustawienia trybu i ewentualnie bron. Nie wymagaja dodatkowych tekstur ani duzych assetow i nie uruchamiaja sie bez zgody gracza.

Zasada publikacji:

- Przyklady sa domyslnie wylaczone.
- Import i priorytet ustawia gracz w zakladce `Mody`.
- Kod moda nalezy uruchamiac tylko z zaufanego zrodla.
